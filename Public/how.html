How it works

Five steps. No sign-up.

  1. 01

    Paste your code

    Any of 14 languages, up to 20,000 characters.

  2. 02

    Pick a mode

    Simplify, Explain, or Both.

  3. 03

    Choose your level

    Beginner, intermediate or concise.

  4. 04

    Review the diff

    See exactly what changed, line by line, before you use it.

  5. 05

    Learn from the notes

    Plain-English bullets explain what the code does and why it changed.

Two engines, one rule: same behaviour

The rule-based engine runs on our server with no AI. It parses your code and only makes changes that cannot alter what it does, and it lists every change in the Notes tab. The AI engine can restructure more, but it can occasionally change behaviour, so run your own tests on the result.
